# Scalper Bot — Pepperstone / cTrader

Phone-run scalping bot for Pepperstone. Connects directly to cTrader's
free Open API over WebSocket — no paid bridge, no backend server.

Open index.html in a browser, or visit this repo's GitHub Pages link.
Enter your Client ID, Client Secret, and Access Token from
openapi.ctrader.com, choose Demo or Live, pick a symbol, and tap Connect.

Test on Demo first before ever switching to Live.
